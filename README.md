# 📖 Overview

Fault Detection and Diagnosis (FDD) is an essential component of smart irrigation systems to ensure reliable operation and early identification of abnormal irrigation behavior.

This project develops an **Autoencoder-based anomaly detection model** that learns normal irrigation patterns from historical irrigation event data. During inference, the model reconstructs the input features, and the reconstruction error is used to determine whether an irrigation event is normal or anomalous.

Detected anomalies are subsequently mapped into irrigation fault categories using a knowledge-based diagnosis approach implemented in the deployment system.

# 📊 Dataset

The model is trained using irrigation event data collected from an IoT-enabled Smart Precision Irrigation system.

Each irrigation event contains the following features:

| Feature | Description |
|----------|-------------|
| Moisture Before | Soil moisture before irrigation |
| Moisture After | Soil moisture after irrigation |
| Duration | Irrigation duration generated by the fuzzy controller |
| Moisture Gain | Difference between moisture after and before irrigation |
| Moisture Rate | Moisture gain per irrigation duration |

---

# ⚙️ Data Preprocessing

The preprocessing pipeline includes:

- Standardization using StandardScaler

# 🧠 Model Architecture

The anomaly detection model is based on an **Autoencoder Neural Network**.

Input:

- Moisture Before
- Moisture After
- Duration
- Moisture Gain
- Moisture Rate

Output:

- Reconstructed input features

Detection is performed by calculating the **Mean Squared Error (MSE)** between the original and reconstructed feature vectors.

---

# 🎯 Hyperparameter Tuning

Hyperparameter optimization is performed using **Keras Tuner**.

Examples of tuned parameters include:

- Number of hidden layers
- Number of neurons
- Latent dimension

The best-performing configuration is selected based on validation loss.

# 🚨 Supported Fault Scenarios

The exported model is capable of supporting diagnosis of irrigation faults such as:

- Sensor Drift
- Sensor Freeze
- Under Irrigation
- Over Irrigation
- Incorrect Fuzzy Rule Base
- Incorrect Membership Function
- Clogged Nozzle
- Low Water Pressure
- Pipe Leakage
- Pipe Blockage
